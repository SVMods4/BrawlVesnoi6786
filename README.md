# Brawl Stars 3D Viewer

Интерактивный 3D-просмотрщик бойцов Brawl Stars в браузере.

## Возможности

- Просмотр 3D-моделей (Colt, Shelly)
- Вращение и масштабирование мышью
- Переключение бойцов по иконкам
- Меню:
  - Скачивание моделей
  - Смена цвета фона
- **BY BURMALDA STARS**

## Как открыть

1. Скачай все файлы
2. Открой `index.html` в браузере

Или через локальный сервер:
```bash
python -m http.server 8000
```

## Файлы

- `index.html` — главная страница
- `Pusia-Bold.otf` — шрифт
- `colt.glb` / `shelly.glb` — 3D модели
- `colt.webp` / `shelly.webp` / `star.webp` — иконки
